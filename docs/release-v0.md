# v0：首个可复用版本

用户于 2026-10-24 接受当前定性重建效果及已知近似，授权固定第一版。Git 标签为 `v0`，Python 包版本为 `0.1.0`，内部方法版本为 `rigid_v0.4`。

## 包含内容

- 单张 RGB 与标定 RGB-D 采集目录两条输入路径，提供示例及中文运行步骤。
- SAM3 自动分割、点选/框选补充和删除物体，类型及质量设置。
- SAM 3D 初始网格、Astra 全资产审查与受约束精修、自动支撑关系与位姿迭代。
- MuJoCo 网格、纹理、凸碰撞体和独立物理/视觉报告。
- 同一场景直接导出 Isaac USD，保留位姿、质量、惯量与碰撞分块，独立 PhysX 动态检查。
- 简化 GUI、结果指标及两种原生预览入口；全部主要流程保留 CLI。

## 验证

64 项本机回归测试通过，单元测试不调用真实模型。新 1440×1080 图片实际完成 SAM3、SAM 3D、Astra 和双模拟器流程，选中两个按钮盒及浅盘；通过 GUI 删除了一个悬空玩偶。MuJoCo 10 秒检查通过，初始最大穿插约 0.093 mm，平均轮廓 IoU 为 0.815。Isaac 10 秒、5000 步动态及支撑检查通过。

另外，在与原生预览相同的图形运行循环中，分别通过物理接口、暂停时修改刚体根位姿、播放时修改刚体根位姿抬高红按钮盒 20 cm，三种情况均下落并落稳；渲染前后图与物理读数相符。此测试未复现用户的鼠标拖拽动作。

证据摘要：[新图完整流程](new_image_validation.json)、[Isaac 下落](isaac_drop_validation.json)、[早期 RGB-D](rgbd_validation.json)、[支撑关系](relations_validation.json)。原始运行、用户新图片和生成模型保留在本地，不随发布上传。本轮没有重新跑完整 RGB-D 模型链路，也没有验证第二台干净机器的安装。

## 已知限制

- 单图绝对尺度、不可见表面、质量与摩擦仍为估计；深度路径要求提供真实标定。
- Astra 的可执行资产修正目前限于锤子、按钮盒模板及轻度网格清理，不是任意类别的完美重建。
- 新图最终视觉评价仍为部分匹配，盘沿厚度、投影及按钮盒相对高度存在误差；这些质量标记不会因发布而改为通过。
- 铰链、抽屉、布料、软体当前仅保存标注，仍按刚体导出；按钮没有可按压关节。
- Isaac 的完整初始穿透检查尚未实现，`physics_check_pass` 为 null，与已通过的动态检查分开。
- 原生预览初始暂停；网页三维预览仅显示几何。用户先前鼠标拖动后未下落的具体原因尚未复现，不归咎于用户操作。
- 不包含 Isaac Lab 任务、抓取验证或已标定多视角几何融合。

安装、输入位置、两条路径的命令和输出查看方式以 [中文 README](../README.md) 为准。模型权重、运行环境、登录凭据不打包，需要在使用机器上配置。

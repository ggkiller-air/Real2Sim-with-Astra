# 单图到 MuJoCo 的实现

本阶段只实现普通刚体，关节/抽屉/布料/软体仍是标注，Isaac Lab 尚未实现。

## 数据与运行边界

场景使用米、千克、弧度，世界右手系 Z-up。原图保存为 EXIF 校正后的 PNG，所有框/点/掩码沿用它的像素坐标。物体 ID、原始网格、原始模型姿态和参数来源保持可追溯。`orientation` 是 wxyz 四元数，`yaw` 为额外世界 Z 轴转角。质量和摩擦默认是估计，模型深度不是传感器测量。

核心服务/MuJoCo、SAM3、SAM 3D 分别运行在独立环境中。后台任务串行，修订号阻止过期修改。失败输出保留；服务重启不会偷偷续跑任务。模型失败不会替换成占位盒。

## 处理步骤

1. SAM3 扫描桌面类别，单独分割机械臂/夹爪与桌面，掩码去重、排除机器人。自动扫描不保证找到所有物体。
2. GUI 提供正负点击点、框选和分割预览。确认后才加入列表；与已有掩码重合时合并到原 ID。图片点选已有对象按掩码命中，而不是重叠的包围框。
3. SAM 3D 使用同一张 MoGe 预测点图生成各资产。保存原始 GLB、颜色、rotation/translation/scale；用官方 `compose_transform` 和 GLB 轴变换转入共同相机坐标系。
4. 对桌面掩码内的预测点作 RANSAC 平面拟合，建立 X 近似朝画面右、Z 沿桌面法向的共同世界坐标。根据假设桌宽赋予米制尺度，明确记录比例来源。桌面背景自动覆盖生成的物体范围。
5. 彩色显示网格与碰撞分离。显示网格简化后将生成的顶点颜色烘焙为三角形纹理图集；CoACD 生成至多 12 个凸碰撞体，按体积分配给定质量。视觉网格质量为零、不参与接触。凸体仍是近似，重叠部分及不可见结构不是物理真值。
6. 实际 MuJoCo 接触驱动有界 XY 消穿插，然后重力落桌提出初始位姿。保存落桌前后的平移和旋转，不以固定关节隐藏悬空。
7. 对落稳后的导出重新进行独立 3 秒检查：1500 次接触采样、初始穿插、位移、转角、末态速度、正确桌面接触和数值警告。质量/摩擦、阈值不为通过检查而调整。
8. MuJoCo 原生渲染原图视角、俯视、侧视和背面。Astra 接收参考图、渲染图、场景参数和物理报告，输出受限 JSON 建议。最多三项 XY（每轴 10 cm）和 yaw（30°）修正；只有原生渲染轮廓 IoU 改善且物理复检通过才采纳。保留被拒建议与证据。Astra 的主观判断不等于视觉真值。

## 降级路径与边界

手工导入网格仍是单凸包碰撞；显式占位预演仍使用包围框底点投影及 AABB 布局。对真实 SAM 3D 输出不要调用旧的 initialize 覆盖共同深度布局。

当前仅单图输入。未知背面、裁切物体、绝对尺寸、质量、摩擦仍有不确定性。短时稳定不证明抓取、任务成功或材料真实；Astra 不会把仅有姿态自由度的问题伪装成几何修复。

## 资产优化阶段

`asset_refinement.py` + `prompts/astra_asset_refinement.txt`：在已有 SAM 3D 结果上提出独立的参数化资产候选。实际 Astra 多模态调用选择模板与参数；后端只接受有限模板和边界内的数值，不执行模型输出代码。锤子分为橡胶锤头、黄色柄和圆滑握把；按钮盒分为双色壳体、底座、按钮杆和圆帽。模板属于结构化近似，不是从照片测出的 CAD。

本阶段保留原始几何、位姿、尺寸、质量/摩擦与场景报告。对照渲染统一相机和光照；候选检查有限顶点、闭合组件及导出可加载性，不宣称动态稳定。组件可能相交，没有布尔融合为单一实体。源网格坐标与规范坐标的变换、候选中心偏移均保存，后续采纳必须尊重这些接口；暂不自动推进场景组装。CLI 内部复用已验证模型计划可加速几何模板迭代，报告区分真实新调用和计划复用。

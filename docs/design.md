# v0.1 设计与后续工作

本阶段目标为 MuJoCo 普通刚体。所有特殊结构只保存类型和备注，不生成关节、柔性或容器内腔。Isaac Lab 后续单独适配。

## 数据与执行

SceneRecord 使用米、千克、弧度，世界右手系 Z-up。原图为校正 EXIF 方向的 PNG，掩码保持其分辨率，框/点使用该 PNG 的像素坐标。

物体 ID 稳定，修正掩码保留名称和用户参数。支撑关系禁止成环；选中物体必须保留其支撑物。参数来源区分 assumed/user/measured。

geometry=none/proxy/imported/sam3d 显式区分无几何、占位、导入与模型生成。导入网格归一化为中心在原点的单位包围盒，按用户宽度恢复比例。原始文件保留；纹理不进入当前 MuJoCo 导出，碰撞为单凸包。

UI 和 agent 使用同一 API。GPU 模型使用独立 Python 子进程；任务串行执行，每项目计算期间禁止编辑。修订号拒绝过期写入。编辑会使当前验证/导出失效，历史文件不删除。服务重启不自动续跑旧任务。

## 当前布局与检查

四点映射将图片映射到给定尺寸的平面；默认整图近似。物体框底部中点映射到桌面，包围盒底面放到桌面或支撑物顶面。不等价于相机或深度恢复。

优化在未锁定物体的原 XY 位置 ±15 cm 内进行 Powell 搜索。目标包括位置偏移、AABB 穿插、桌边越界和支撑范围溢出。质量、摩擦、尺寸、朝向、高度保持不变。降低目标函数不代表物理检查通过。

检查独立加载 MuJoCo，逐步采样接触，报告初始穿插、末态位移/转角/速度、预期支撑接触、数值警告和模拟时间。默认 3 秒，视觉一致性始终单独报告为未验证。

## 后续

1. 获得 SAM 3D 权重后验证硬件、推理、网格朝向和模型布局坐标转换。
2. 在相同输入上对照 REST3D，再选择支撑组优化和仿真反馈的集成方式。
3. 借鉴 φ-Scene 的支撑依赖装配与距离场消除穿插，替换当前 AABB 近似。
4. 根据 UI 标注逐类加入关节/软体，之后接入 Isaac Lab。

当前实现不是 REST3D 或 φ-Scene 的复现。研究参考分别见 https://github.com/ShirleyMaxx/REST3D 和 https://phi-scene.github.io/。

第一版怎样使用

  1. 上传图片，输入类别自动分割，或框选并添加正负点。先点击“新物体提示”可避免覆盖已有掩码。
  2. 勾选需要的实例。特殊类型只保存标注，不改变刚体模型。
  3. SAM 3D 需要独立环境和权重权限。暂未具备时，可导入已有网格，或明确选择“占位预演”测试流水线。
  4. 按远左、远右、近右、近左顺序标桌面四角，填写桌面尺寸。初始布局采用框底部投影近似，不是深度重建。
  5. 调整尺寸、位置与支撑关系，保存后运行优化。优化使用保守包围盒搜索，需要人工复核。
  6. 运行物理检查并导出。下载的 ZIP 解压后用 MuJoCo 加载 scene.xml。

凸包会填平网格凹洞。当前不支持容器内部放置、关节运动和软体变形。模型输出、手动参数和检查结果都保留来源。

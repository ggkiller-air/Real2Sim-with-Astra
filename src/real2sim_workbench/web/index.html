只需要做一点选择

上传后，SAM3 自动寻找常见桌面物体并合并重复分割。删除不需要的物体，或用正负点击点、框选补充遗漏；类型和重量在物体卡片上选择，修改自动保存。

生成时自动建立支撑平面、安排布局、减少穿插并运行短时物理检查。背景使用简化桌面与地面；单张照片的尺寸和接触位置仍是估计，不能保证覆盖所有物体或还原遮挡关系。

单图放入 data/image/；深度采集包整体放入 data/depth/，然后刷新列表并导入。 确认后依次运行 SAM 3D、Astra 资产优化、布局与物理检查、多视角评估。 Result 可一键打开 MuJoCo 或 Isaac Sim 桌面窗口。特殊类型目前只保存标注，仍作为普通刚体处理。
